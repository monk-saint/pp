MoFi: Mobile & WiFi Speed Test — Privacy Policy

Last updated: 15 October 2026

Package: app.redbanana.mofispeedtest

MoFi measures download speed, upload speed, ping, and jitter on the network you are using. The app has no account and no developer-operated account server. We do not sell personal data.

What stays on your device

  • Test results: time, download and upload speed, ping, jitter, bytes transferred, duration, and test mode.
  • The test server host name, whether the connection was Wi-Fi, mobile, or other, and whether a VPN was active.
  • An optional label you type, up to 60 characters.
  • A local key derived from a hash of the network handle, used only to group results on this phone. It is not a Wi-Fi name.

The app does not read your Wi-Fi name, location, contacts, or files. History stays in an on-device database. You can delete one result or clear history. Android backup is disabled. Uninstalling the app removes this data.

Speed test traffic

A test needs the internet. The app downloads data from, and uploads a block of non-personal bytes to, the HTTPS test server used for that run. Those requests include the byte count and a timing value so the measurement is not served from cache. The upload is not your photos, messages, or files.

The test server and your network can see the device IP address, as with any HTTPS connection. MoFi does not send your history, labels, or the local network key to Sushila Creatives.

Sharing

If you tap share, the app creates an image of that result and opens the Android share sheet. The destination is one you choose. Shared images in the app cache are temporary.

Advertising

This version does not request the Android advertising ID, and it does not ship a production advertising app id. Debug builds can show Google test ads after a consent prompt from Google’s User Messaging Platform. If a later release turns on production ads, this page will be updated first. Speed results are not sent to an ad network.

Permissions

  • Internet — run the speed test.
  • Network state — tell Wi-Fi, mobile, and VPN apart, and notice when the network changes. This does not use location or the Wi-Fi name.

Children

MoFi does not knowingly collect personal information from children.

Changes

This page will be updated if these data practices change.
