File Info — Privacy Policy

Last updated: 26 September 2026

Chrome extension

File Info shows size, dimensions, aspect ratio, and file details for an image, PDF, video, audio file, or local file you choose. It does not have an account. File contents are not sent to Sushila Creatives. We do not sell personal data.

What the extension reads

  • Active tab and scripting — read the file or image on the tab you invoke the extension from.
  • Downloads — identify a downloaded file you ask about.
  • Context menus — add the File Info action to the menu.
  • Local files — only if you grant the optional file access, and only for a file you open.

To read size and type, the extension may request the URL you are already viewing, including a HEAD or GET for that file. That request goes to the site hosting the file, the same way your browser would load it. It is not sent to a Sushila Creatives server.

Advertising

File Info does not include an advertising or analytics SDK.

Children

File Info does not knowingly collect personal information from children.

Changes

This page will be updated if these data practices change.
